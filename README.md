# 🧮 Python CLI Smart Calculator

A command-line based smart calculator built using Python.  
It performs a wide range of mathematical, geometrical, and scientific calculations.

---

## 🚀 Features

- Basic Operations (Addition, Subtraction, Multiplication, Division)
- Average & Percentage Calculator
- Geometry (Area, Perimeter, Volume)
- Surface Area Calculations
- Temperature Converter
- BMI Calculator
- Trigonometric Functions
- Table Generator
- Speed, Distance & Time calculations

---

## 🛡️ Improvements Made

- Removed unsafe `eval()` usage
- Implemented safe input handling using `float()`
- Fixed logical and mathematical errors
- Structured code using `main()` function
- Added error handling (try-except)
- Clean and user-friendly CLI interface

---

```bash
python calculator.py
